# 애드체크 비즈 사용설명서 (광고주용)

> 기능이 추가·변경될 때마다 버전을 올리고 해당 부분만 고친다 (업그레이드 방식).
> 맨 아래 "변경 이력"에 무엇이 바뀌었는지 한 줄씩 남긴다.

- 현재 버전: v0.3
- 접속 주소: https://adcheck-biz-vibethon.vercel.app (https라서 카메라 켜기 사용 가능)
- 크리에이터용 짝 앱(애드체크): https://adcheck-vibethon.vercel.app
- 권장 환경: 휴대폰 브라우저 (크롬, 사파리, 삼성 인터넷)

## 1. 이 앱은
체험단·협찬 캠페인을 운영하는 광고주가 **인플루언서들이 올린 게시물의 광고 표시를 한 번에 검수**하고, 문제가 있는 인플루언서에게 보낼 **수정 요청 메시지**를 만들어 주는 도구입니다.
검수 기준은 크리에이터용 애드체크와 같습니다 (공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 요약, 참고용).

## 2. 시작하기
1. 접속 주소를 휴대폰으로 엽니다.
2. 처음 열면 샘플 캠페인 2개(베이글하우스 체험단, 글로우랩 유료 광고)와 게시물 12개가 들어 있습니다.

## 3. 화면 안내
| 화면 | 하는 일 |
|---|---|
| 대시보드 | 캠페인 선택, 게시물 수·준수율·조치 필요 수, 판정별 게시물 수 차트, 조치가 필요한 게시물 목록 |
| 게시물 | 캠페인 게시물 목록(전체 / 조치 필요 / 문제 없음), 게시물 등록, 상세 검수·수정 요청·상태 관리 |
| 화면 스캔 | 다른 휴대폰·모니터에 띄운 게시물을 여러 장 찍어 가장 선명한 장면의 글자를 읽고 검수 |
| 캠페인 | 캠페인 목록·선택·추가, 앱 정보, 샘플 데이터로 초기화 |

## 4. 기능별 사용법
### 4-1. 캠페인 만들기
1. **캠페인** 탭 → 캠페인 이름, 브랜드·가게 이름 입력
2. 인플루언서에게 제공한 대가(현금·원고료 / 무료 제품·서비스 / 할인·쿠폰) 선택
3. **캠페인 만들기** → 게시물 탭으로 이동합니다. 이후 게시물마다 대가를 다시 입력할 필요가 없습니다.

### 4-2. 게시물 등록·검수
1. **게시물** 탭 → 오른쪽 아래 **+**
2. 인플루언서 계정(@ 없이 써도 됨), 플랫폼, 게시물 글을 붙여넣기
3. **등록하고 검수하기** → 바로 점수와 판정(적합 / 보완 필요 / 위반 위험)이 나옵니다.

### 4-3. 수정 요청 보내기
1. 게시물을 누르면 검수 결과와 **수정 요청 메시지**가 나옵니다.
   - 메시지에는 인사, 문제 항목, **수정 예시 글**, 심사지침 안내가 들어 있습니다.
2. **메시지 복사** → 인스타그램 DM이나 카카오톡으로 인플루언서에게 보냅니다. 복사하면 상태가 자동으로 **수정 요청함**이 됩니다.
3. 인플루언서가 글을 고치면 **인플루언서가 고친 글 붙여넣기** 칸에 넣고 **수정본 다시 검수** → 적합이면 상태가 자동으로 **확인 완료**가 됩니다.
- 조치 상태(미조치 / 수정 요청함 / 확인 완료)는 직접 바꿀 수도 있습니다.

### 4-4. 화면 스캔으로 등록하기
글을 복사할 수 없을 때(인플루언서가 휴대폰으로 보여 줄 때, 회의실 모니터에 띄웠을 때) 화면을 찍어서 등록합니다.
화면을 찍으면 깜빡임 때문에 가로 줄무늬가 생기고 손떨림으로 흐려지므로, 여러 장을 찍어 가장 선명한 장면을 고릅니다.
1. **화면 스캔** 탭 → 위에서 캠페인 선택
2. 셋 중 하나를 고릅니다.
   - **카메라 켜기** → 화면 전체가 들어오게 맞추고 **연속 8장 촬영** (휴대폰을 최대한 움직이지 마세요)
   - **사진 여러 장 불러오기** → 휴대폰 카메라 앱으로 같은 화면을 여러 장 찍어 두었다가 한꺼번에 선택
   - **예시 화면으로 체험** → 카메라 없이 흔들리고 줄무늬가 생긴 예시 사진 6장으로 체험
3. **장면 고르기**: 점수가 높은 순으로 보여 줍니다. 1위에 **추천**, 여러 장을 겹쳐 줄무늬를 지운 장면에 **합성** 표시. 장면마다 선명도(1위 대비)와 줄무늬(적음/보통/많음)가 나옵니다. 다른 장면을 누르면 바꿀 수 있습니다.
4. **이 장면으로 글자 읽기** → 진행 막대가 끝나면 인식된 글이 나옵니다. 사진과 비교해 틀린 글자를 고칩니다.
5. 인플루언서 계정(화면 맨 위 계정 이름을 자동으로 채움)과 플랫폼을 확인하고 **게시물로 등록하고 검수** → 게시물 탭에서 검수 결과와 수정 요청 메시지가 바로 열립니다.
- 카메라 버튼이 안 보이면: 보안 연결(https)이 아닌 주소입니다. 사진 여러 장 불러오기를 이용하세요.
- 처음 글자를 읽을 때는 한글 사전을 받느라 10~20초 걸립니다. 인터넷이 없거나 인식에 실패하면 사진을 보며 글을 직접 입력할 수 있습니다.

### 4-5. 대시보드 보기
- **준수율** = 적합 게시물 ÷ 전체 게시물
- **조치 필요** = 적합이 아니면서 아직 확인 완료가 아닌 게시물
- 조치가 필요한 게시물을 누르면 바로 상세 검수 화면이 열립니다.

## 5. 자주 묻는 질문
- **게시물 링크만 넣으면 안 되나요?** 인스타그램·블로그는 외부에서 글을 가져오는 것을 막고 있어, 글을 복사해 붙여넣거나 화면 스캔을 이용해야 합니다.
- **찍은 사진이 서버로 가나요?** 아니요. 장면 고르기와 글자 인식 모두 이 휴대폰 브라우저 안에서 처리됩니다.
- **메시지를 앱에서 바로 보내나요?** 아니요. 복사해서 평소 쓰는 DM·카카오톡으로 보내면 됩니다.
- **데이터는 어디에 저장되나요?** 이 기기 브라우저에만 저장됩니다.
- **처음 상태로 돌리려면?** 캠페인 → 샘플 데이터로 초기화.
