## 이슈 / 메모
- 협업 기능의 DM 발송은 시연용: 실제 SNS로 보내지 않고 발송 기록만 저장. 실제 발송은 문구 복사 후 각 SNS에서
- '샘플 데이터로 초기화'가 협업 데이터(크리에이터·행사·발송 기록·신청자)까지 함께 되돌림
- node_modules: tesseract.js 설치로 이 폴더에 자체 node_modules가 생김 (나머지는 상위 폴더와 같은 버전)
- 카메라는 https/localhost에서만 동작 → 휴대폰 시연은 배포 링크로 하거나 사진 불러오기·예시 화면 사용
- 처음 글자 인식 때 한글 언어 데이터를 인터넷(CDN)에서 받음 → 시연 전에 한 번 미리 실행해 두면 빠름
- 예시 6장 + 합성본 OCR 정확도(원문 대비 글자 일치율): 추천 장면 100%, 합성본 81%(위치 맞추기 전 36%), 줄무늬 심한 장 33~95%, 많이 흐린 장 0~1%
  → "여러 장 찍고 고르기"가 필요한 근거. 줄무늬 감점은 완만하게(흐림이 OCR에 더 치명적)
- 점수 순위 2위 이하는 OCR 결과와 완전히 일치하지 않음(모아레가 선명도를 부풀림). 1위 선택은 정확
