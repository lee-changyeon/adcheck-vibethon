# 기획서 — 애드체크 비즈 (광고주용)

> 크리에이터용 **애드체크**(`../docs/01_기획서.md`)의 짝이 되는 광고주용 앱.
> (2026-11-17 10:12 기획 · 10:31 `sns-ma/advertiser` 폴더를 독립 작업 환경으로 분리)
> 10:40 **화면 스캔** 추가 — 모니터·휴대폰 화면을 연속 촬영해 가장 선명한 장면을 골라 글자를 읽고 검수

## 1. 기본 정보
- 앱 이름: **애드체크 비즈 (AdCheck Biz)** — 광고주용 뒷광고 검수 도구
- 한 줄 소개: **체험단·협찬 캠페인을 운영하는 소상공인·브랜드 마케터**가 **애드체크를 쓰지 않는 인플루언서들의 게시물을 하나하나 확인하기 어려운데**, 이 앱은 **캠페인 게시물을 모아 한 번에 검수하고, 문제 있는 인플루언서에게 보낼 수정 요청 메시지까지 만들어 준다.**

## 2. 문제 정의
- 대상 사용자: 체험단 10~30명을 모집하는 동네 카페·식당 사장님, 화장품 브랜드 마케팅 담당자, 소규모 광고대행사
- 지금 겪는 불편:
  - 인플루언서마다 표시 방식이 제각각이고, 모두 애드체크 같은 도구를 쓰는 것은 아님
  - 게시물 수십 개를 하나씩 열어 "협찬 표시가 첫 줄에 있나"를 눈으로 확인해야 함
  - 문제를 찾아도 무엇을 어떻게 고쳐 달라고 할지 문구를 매번 새로 써야 함
- 왜 광고주가 챙겨야 하나:
  - 뒷광고가 적발되면 **광고를 의뢰한 사업자도 표시광고법에 따른 제재 대상**이 될 수 있음
  - 공정위 점검은 이미 올라간 글을 적발한 뒤 시정을 요청하는 방식 → 광고주가 **먼저 검수**하면 위험을 줄일 수 있음

## 3. 해결 방법
- 핵심 아이디어: **캠페인(브랜드·제공한 대가)** 을 한 번 등록하면, 게시물은 **인플루언서 계정 + 글**만 붙여넣으면 크리에이터용과 같은 규칙으로 자동 검수
- 크리에이터용과의 관계:
  | 구분 | 애드체크 (크리에이터용) | 애드체크 비즈 (광고주용) |
  |---|---|---|
  | 사용자 | 글을 쓰는 인플루언서 | 협찬을 맡긴 광고주 |
  | 단위 | 내 글 1개 | 캠페인 1개 = 게시물 여러 개 |
  | 결과 | 점수 + 고친 글 | 인플루언서별 상태 + **수정 요청 메시지** |
  | 조치 | 내가 고쳐서 올림 | 요청 → 수정 확인까지 **진행 상태 관리** |
  | 점검 규칙 | `src/data/rules.ts` | 같은 규칙 복사본 (`npm run sync-rules`로 맞춤) |

## 4. 핵심 기능 (우선순위 순)
| 순위 | 기능 | 사용자가 얻는 것 | 필수 여부 |
|---|---|---|---|
| ① | 캠페인 등록 (이름·브랜드·제공한 대가) | 게시물마다 대가를 다시 입력할 필요 없음 | 필수 |
| ② | 게시물 일괄 검수 (계정·플랫폼·글 → 판정) | 수십 개 게시물의 위험을 한눈에 | 필수 |
| ③ | 수정 요청 메시지 생성·복사 + 조치 상태 (미조치 → 요청함 → 확인 완료) | 연락 문구 작성 시간 절약, 누락 방지 | 필수 |
| ④ | 대시보드 (판정 분포 차트, 조치 필요 목록) | 캠페인 전체 준수율 파악 | 여유 있으면 |
| ⑤ | **화면 스캔**: 다른 기기 화면을 연속 8장 촬영 → 선명도·줄무늬 점수로 가장 좋은 장면(또는 합성본) 추천 → 글자 인식(OCR) → 등록·검수 | 글을 복사할 수 없는 상황(인플루언서 휴대폰·회의실 모니터)에서도 바로 검수 | 추가 |
- 화면 스캔이 필요한 이유 (사용자 문제 정의): 모니터·휴대폰 화면을 찍으면 **화면 깜빡임(주사율)과 카메라 셔터가 어긋나 가로 줄무늬·모아레**가 생기고 손떨림으로 흐려져 한 장으로는 글자를 읽기 어렵다 → **여러 장을 찍어 선명한 장면을 고르면** 내용을 파악·분석할 수 있다
  - 예시 6장 실험: 가장 흐린 장은 글자 일치율 0~1%, 앱이 추천한 장면은 100%

## 5. 화면 구성
| 화면 | 주요 내용 |
|---|---|
| 대시보드 | 캠페인 선택, 게시물 수·준수율·조치 대기 수, 판정 분포 차트, 조치가 필요한 게시물 |
| 게시물 | 캠페인 게시물 목록(판정·조치 상태 필터), + 버튼으로 게시물 등록, 상세에서 문제 항목·수정 요청 메시지·상태 변경·수정본 재검수 |
| 캠페인 | 캠페인 목록·추가·선택, 샘플 데이터로 초기화, 앱 정보 |
| 화면 스캔 | 카메라 켜기(연속 8장) / 사진 여러 장 불러오기 / 예시 화면 → 장면 고르기(추천·합성·선명도·줄무늬) → 글자 확인·수정 → 게시물로 등록하고 검수 |

## 6. 시연 시나리오 (1분 30초, 크리에이터용 시연 뒤에 이어서)
1. 대시보드: "베이글하우스 신메뉴 체험단" 게시물 8개 중 **위반 위험 4개**, 판정 분포 차트
2. 게시물: 위반 게시물 하나 열기 → 문제 항목 + **수정 요청 메시지** 복사 → 상태 "수정 요청함"
3. 인플루언서가 고친 글을 붙여넣고 재검수 → **적합**, 상태 "확인 완료" → 대시보드 준수율 상승
4. 화면 스캔: "인플루언서가 휴대폰으로 보여 준 게시물, 글을 복사할 수 없을 때" → 카메라로 연속 촬영(또는 **예시 화면으로 체험**)
   → 줄무늬·흐림이 섞인 장면들 중 **추천** 장면 확인 → 글자 인식 → **게시물로 등록하고 검수** → `@daegu_brunch_log` 45점 위반 위험(#협찬이 해시태그 맨 끝에 묻힘) → 수정 요청 메시지

## 7. 하지 않을 것 (범위 밖)
- 인스타그램·블로그 링크에서 글 자동 수집 (API 제한) → 글은 붙여넣기 또는 화면 스캔
- 인플루언서에게 메시지 자동 발송 → 복사해서 DM·카카오톡으로 직접 전달
- 회원가입, 팀 공유, 서버 저장 → 이 기기 브라우저에 저장
- 법률 자문 → 참고용 검수임을 화면에 안내
