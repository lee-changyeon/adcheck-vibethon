# 테스터 모집 안내 문구 — 애드체크

구글 플레이 개인 개발자 계정은 정식 출시 전에 **비공개 테스트에 12명 이상이 14일 연속 참여**해야 한다. 중간에 빠지는 사람이 생길 수 있으므로 **15~20명**을 목표로 모은다.

- 테스터 조건: 안드로이드 휴대폰 + 구글 계정(Gmail). 아이폰은 참여할 수 없다.
- 받을 정보: 테스트용 **Gmail 주소** 하나뿐 (구글 플레이 테스터 목록에 넣는 용도)
- 날짜 칸 `[ ]`은 비공개 테스트를 열 때 채운다.

## 운영 메모 (개발자용)

- **테스터 목록 방식:** 플레이 콘솔 「비공개 테스트 › 테스터」에서 ① 이메일 목록에 Gmail을 직접 넣거나 ② Google 그룹을 만들어 테스터가 스스로 가입하게 할 수 있다. 사람이 많고 각자 가입하게 하려면 ②가 편하다(그룹 주소만 공유하면 됨, Gmail을 따로 받지 않아도 됨).
- **14일 계산:** 12명 이상이 **연속 14일 동안 테스트에 참여(옵트인)한 상태**여야 한다. 중간에 나간 사람은 다시 세지 않으므로 넉넉히 모은다.
- **프로덕션 신청 때 질문:** 테스트를 마치고 정식 출시를 신청할 때, 테스터를 어떻게 모았는지, 어떤 의견을 받았고 무엇을 고쳤는지 묻는다. 받은 의견과 고친 내용을 `03_작업목록.md`에 기록해 둔다.
- **개인정보:** 받은 Gmail 주소는 저장소·문서에 적지 않는다. 테스트가 끝나면 콘솔 목록과 받은 메시지에서 지운다.
