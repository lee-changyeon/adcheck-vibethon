# 기획서

> 주제 공개 후 15분 안에 채운다. 기획이 바뀌면 이 문서부터 고친다.
> (본 대회 · 2026-11-17 09:37 시작 · 제출 마감 16:30)

## 1. 기본 정보
- 대회 주제: 전공을 연계한 문제해결 (전공: SNS마케팅)
- 앱 이름: **애드체크 (AdCheck)** — 뒷광고 예방 체크기
- 한 줄 소개: **협찬을 처음 받는 소규모 인플루언서·대학생 크리에이터**가 **광고 표시 규칙을 몰라 의도치 않게 뒷광고를 하게 되는데**, 이 앱은 **올리기 전 글을 붙여넣으면 공정위 기준으로 위반을 찾아 주고 고친 문구까지 만들어 준다.**

## 2. 문제 정의
- 대상 사용자: 팔로워 1천~1만 명, 카페·식당·화장품 협찬을 막 받기 시작한 대학생 인스타그래머·블로거
- 지금 겪는 불편: 업체가 "자연스럽게 올려 주세요"라고만 하고, 본인은 "#협찬"을 해시태그 맨 끝에 붙이면 된다고 생각함
- 기존 방법의 한계:
  - 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」은 문서가 길고 법률 용어라 읽지 않음
  - 표시를 **어떤 말로, 어디에** 해야 하는지(첫 부분, 한글, 해시태그에 묻히지 않게)는 잘 알려져 있지 않음
  - 위반이 드러나면 팔로워 신뢰를 잃고, 광고를 맡긴 업체도 제재 위험

### 문제의 근거 (2026-11-17 조사)
| 근거 | 내용 | 출처 |
|---|---|---|
| 적발 규모 | 공정위가 2021~2025년 모니터링한 SNS 뒷광고 의심 게시물 **약 10만 9천 건** (2025년 2만 2,675건) | 서울경제TV, SBS 뉴스 |
| 적발 유형 | 2024년 점검: **부적절한 위치 39.4%**, 표시 안 함 26.5%, 부적절한 표현 17.3% | 공정위 국민생각함, 서울경제 |
| 표시 실태 | 국내 상위 인플루언서 광고 게시글 582건 중 대가를 밝힌 글 **29.9%** | 한국소비자원 조사 (어패럴뉴스 보도) |
| 기준 강화 | 2024-09-01 시행 개정 심사지침: 본문 중간·댓글·'더보기' 안의 표시는 인정 안 됨, 국내 대상이면 AD·PR·Sponsor 등 외국어 표현도 부적절 | 어패럴뉴스, 김앤장 |

→ 적발 유형 상위 3개(위치·미표시·표현)가 애드체크의 핵심 점검 규칙(표시 위치·표시 없음·애매한 표현)과 일치한다.
→ 공정위 점검은 **이미 올라간 글을 적발한 뒤 시정을 요청**하는 사후 방식이라, **올리기 전 예방** 도구가 필요하다.

## 3. 해결 방법
- 핵심 아이디어: **받은 대가 + 올릴 글**을 넣으면 규칙 검사로 위반 항목을 빨강·노랑으로 표시하고, **규칙에 맞게 고친 글**을 바로 복사할 수 있게 해 준다
- 차별점:
  - 법 조문 대신 **내 글 기준**으로 "무엇이, 왜 문제인지" 알려 줌
  - 점검만 하고 끝나지 않고 **바로 올릴 수 있는 수정본**을 만들어 줌
  - 외부 서버·AI 없이 규칙 기반이라 **결과가 일정하고 즉시** 나옴 (시연이 멈추지 않음)
  - 점검 이력 통계로 **내가 자주 틀리는 항목**을 보여 줘 습관을 고치게 함

**애드체크만의 차별점**
1. **한국 공정위 기준** — 해외 도구가 정답으로 보는 "#ad", "Sponsored"를 문제로 잡음
2. **올리기 전 예방** — 사후 적발이 아니라 게시 직전 점검
3. **고친 글 자동 생성** — 점수만이 아니라 바로 복사해 올릴 수정본 제공
4. **개인 크리에이터용 · 무료 · 로그인 없음** — 해외 도구 대부분은 광고주용 유료 플랫폼
5. **교육·습관 교정** — 자주 틀리는 항목 통계 + 표시 규칙 가이드

> 검색으로 찾지 못했다고 존재하지 않는다고 단정할 수는 없음. 발표 시 "국내 기준의 사전 점검 도구는 찾지 못했다"로 표현.

### 짝 앱: 애드체크 비즈 (광고주용)
애드체크를 쓰지 않는 인플루언서의 글은 광고주가 검수해야 한다. 같은 점검 규칙으로 **캠페인 게시물을 일괄 검수하고 수정 요청 메시지를 만드는 광고주용 앱**을 `advertiser/` 폴더에 따로 만들었다 (독립 작업 환경, 문서: `advertiser/docs/`).
→ 인플루언서는 **올리기 전에**(애드체크), 광고주는 **올라온 뒤에**(애드체크 비즈) 점검해 뒷광고를 양쪽에서 막는다.

## 4. 핵심 기능 (우선순위 순)
| 순위 | 기능 | 사용자가 얻는 것 | 필수 여부 |
|---|---|---|---|
| ① | 광고 표시 점검 (플랫폼·받은 대가·글 → 위반 항목과 점수) | 올리기 전에 뒷광고 위험을 앎 | 필수 |
| ② | 고친 글 제안 + 복사 | 바로 규칙에 맞는 글을 올림 | 필수 |
| ③ | 점검 이력과 통계 (자주 틀린 항목 차트) | 내 습관을 고침 | 여유 있으면 |
| ④ | 표시 규칙 가이드 (좋은 예·나쁜 예) | 규칙을 한 화면에서 배움 | 여유 있으면 |

## 5. 화면 구성
| 화면 | 주요 내용 |
|---|---|
| 점검 | 플랫폼·받은 대가·업체명·글 입력, 예시 글 넣기, 점검 결과(점수·항목별 설명), 고친 글 복사 |
| 이력 | 지금까지 점검한 글 목록(점수·판정), 누르면 상세 결과 |
| 통계 | 점검 수·평균 점수·통과율, 자주 틀린 항목 차트 |
| 가이드 | 표시 규칙 요약, 좋은 예·나쁜 예, 데이터 초기화, 앱 정보 |

## 6. 시연 시나리오 (2분)
1. 점검: "예시 글 넣기" → 해시태그 끝에 `#thanksto베이글하우스`만 붙은 협찬 글 → **위반 위험 30점** (표시 위치·해시태그에 묻힘·애매한 표현)
2. "고친 글" 복사 → 첫 줄에 `[협찬] 베이글하우스로부터 제품을 무상으로 제공받아 작성한 글입니다.` 가 붙은 수정본 → 다시 점검하면 **적합**
3. 통계: "가장 많이 틀린 항목은 '표시 위치가 뒤쪽'" 차트 → 가이드에서 규칙 확인

## 7. 하지 않을 것 (범위 밖)
- 회원가입/로그인, 인스타그램 계정 연동, 이미지·영상 속 표시 판독, AI 문장 생성
- 법률 자문: 앱 결과는 공정위 심사지침을 바탕으로 한 **참고용 점검**임을 화면에 안내
