## 2. 스토어 등록 방식 비교와 추천

| | ① PWA만 | ② TWA (Bubblewrap) → 구글 플레이 | ③ Capacitor → 안드로이드·iOS | ④ PWABuilder |
|---|---|---|---|---|
| 무엇인가 | 웹앱을 "홈 화면에 추가"로 설치 | 크롬이 PWA를 전체 화면으로 띄우는 안드로이드 앱 껍데기 | 웹 코드를 앱 안에 넣고 웹뷰로 실행, 네이티브 기능 플러그인 사용 | 웹사이트에서 주소만 넣으면 TWA·iOS 패키지 생성 (②③을 도구로 대신) |
| 스토어 | 없음 | 구글 플레이 | 구글 플레이 + 애플 앱스토어 | 구글 플레이(+iOS 실험적) |
| 계정 비용 | 0원 | 구글 25달러 1회 | 구글 25달러 + 애플 연 99달러 | ②③과 같음 |
| 추가 장비 | 없음 | JDK·안드로이드 SDK(Bubblewrap이 설치해 줌) | iOS 빌드에 **맥 + Xcode 필수** | 없음(웹에서 생성) |
| 난이도 | 낮음 | 낮음~중간 | 중간~높음 | 낮음 |
| 업데이트 | Vercel 배포 즉시 반영 | **Vercel 배포 즉시 반영** (앱 재심사 불필요) | 웹 코드가 앱에 들어가므로 앱 재빌드·재심사 필요 | ②와 같음 |
| 현재 코드 변경 | PWA 요건 추가 | PWA 요건 + `assetlinks.json` | PWA 요건 대부분 + Capacitor 설정, 라우터·저장소·링크 동작 확인 | ②와 같음 |
| 심사 위험 | 없음 | 낮음 (PWA 품질만 맞으면 됨) | **iOS는 높음**: 애플 심사지침 4.2(최소 기능) — "웹사이트를 감싼 앱"은 반려되기 쉬움 | ②와 같음 |

### 추천

1. **1단계 — PWA로 만들기 (필수, 모든 경로의 바탕)**
   매니페스트·아이콘·서비스 워커를 넣으면 지금 바로 안드로이드·iOS 모두 "홈 화면에 추가"로 앱처럼 쓸 수 있다. 비용 0원.
2. **2단계 — 구글 플레이는 TWA(Bubblewrap)로**
   애드체크는 서버가 없고 데이터도 기기 안에만 있어 TWA와 가장 잘 맞는다. 웹을 고치면 앱도 바로 바뀐다. PWABuilder로 해도 결과는 같다(처음이면 PWABuilder가 더 쉬움).
3. **3단계 — iOS는 미루거나 선택**
   iOS 사용자는 사파리 "홈 화면에 추가"로 충분히 쓸 수 있다. 앱스토어에 꼭 올리려면 Capacitor를 쓰되, 4.2 반려를 피하려고 **네이티브 기능**(공유 시트로 고친 글 보내기, 클립보드, 오프라인 동작, 알림 등)을 더하는 것이 좋다. 맥과 연 99달러가 필요하므로 구글 플레이 반응을 보고 결정한다.

### 개인 개발자가 알아 둘 구글 플레이 조건

- 2023년 11월 이후 만든 **개인 개발자 계정은 정식 출시 전에 비공개 테스트**(테스터 12명 이상이 14일 연속 참여)를 거쳐야 한다. → 친구·학과 동기 12명을 미리 모을 것. 출시 일정에서 가장 오래 걸리는 단계.
- 신원 확인(신분증), 개발자 연락처 이메일(스토어에 공개됨)이 필요하다. 공개용 이메일을 따로 만드는 것을 권장.

#### 개인정보 관련 사실 확인 (처리방침의 근거)

- 입력한 글·브랜드·점검 이력은 `useLocalStorage`로 **브라우저 localStorage에만 저장**된다 (`adcheck.draft`, `adcheck.history`).
- 소스 코드에 `fetch`·외부 API 호출·분석 도구(GA 등)·광고 SDK가 **없다**. 점검은 `src/data/rules.ts`의 함수가 기기 안에서 계산한다.
- 외부로 나가는 요청은 두 가지뿐이다: ① Vercel 서버에서 앱 파일 받기(Vercel은 일반적인 접속 기록을 남길 수 있음), ② jsDelivr CDN에서 Pretendard 폰트 받기. 폰트를 직접 보관(P10)하면 ②는 없어진다.
- 클립보드는 사용자가 "고친 글 복사"를 누를 때만 쓰기만 한다(읽지 않음).

   앱 화면 파일은 호스팅 업체(Vercel)를 통해 전달되며, 이 과정에서 호스팅 업체가 접속 IP·시간 등 일반적인 접속 기록을 보안·운영 목적으로 처리할 수 있습니다. [폰트를 외부 CDN에서 받는 동안에는: 글꼴 파일을 jsDelivr CDN에서 받아 오며 같은 성격의 접속 기록이 남을 수 있습니다.]
