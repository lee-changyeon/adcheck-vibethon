# 애드체크 사용설명서

> 기능이 추가·변경될 때마다 버전을 올리고 해당 부분만 고친다 (업그레이드 방식).
> 맨 아래 "변경 이력"에 무엇이 바뀌었는지 한 줄씩 남긴다.

- 현재 버전: v1.6
- 접속 주소: https://adcheck-vibethon.vercel.app
- 광고주용 짝 앱(애드체크 비즈): https://adcheck-biz-vibethon.vercel.app
- 소스 코드(GitHub, 두 앱 함께): https://github.com/lee-changyeon/adcheck-vibethon
- 권장 환경: 휴대폰 브라우저 (크롬, 사파리, 삼성 인터넷)

## 1. 이 앱은
협찬 글을 올리기 전에 붙여넣으면, 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 기준으로 **뒷광고 위험을 찾아 주고 규칙에 맞게 고친 글까지 만들어 주는** 광고 표시 점검기입니다.
결과는 참고용이며 법률 자문이 아닙니다.

## 2. 시작하기
1. 접속 주소를 휴대폰으로 엽니다.
2. 처음 화면은 **홈**입니다. 큰 「애드체크」 제목 아래 **지금 점검하기** 버튼이 있고, 그 아래 흰 카드의 점검·이력·통계·가이드 바로가기 4개로 각 화면에 들어갑니다.
3. 처음 열면 이력·통계는 비어 있습니다. 점검 화면의 **예시 글로 체험하기**로 바로 써 볼 수 있습니다.
4. (권장) 앱으로 설치하기
   - 안드로이드 크롬: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   - 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**
   - 설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 **인터넷 없이도** 모든 기능을 쓸 수 있습니다.
   - 안드로이드에서 앱 아이콘을 길게 누르면 **점검하기**·**점검 이력** 바로가기가 나옵니다.

## 3. 화면 안내
| 화면 | 하는 일 |
|---|---|
| 홈 | 앱 소개(큰 제목·일러스트), 지금 점검하기 버튼, 점검·이력·통계·가이드 바로가기 4개, 최근 점검 카드(최근 점수·판정, 기록이 없으면 체험 안내), 사용 3단계, 「첫 줄에 #협찬」 띠 배너(가이드로 이동), 안심 안내. 하단 탭 **홈** 또는 상단 로고를 누르면 언제든 돌아옵니다 |

## 4. 기능별 사용법
### 4-1. 글 점검
1. **점검** 탭에서 올릴 곳(인스타그램·블로그·유튜브)을 고릅니다.
2. 업체에서 받은 것(현금·원고료 / 무료 제품·서비스 / 할인·쿠폰 / 대가 없음)을 고릅니다.
3. 업체 이름(선택)과 올릴 글을 붙여넣습니다. 블로그·유튜브는 **첫 줄을 제목**으로 봅니다.
4. **점검하기** → 점수와 판정, 문제 항목이 나옵니다.
- 처음이라면 **예시 글로 체험하기** 상자의 드롭다운에서 예시 7개 중 하나를 고르면 입력 칸에 바로 채워집니다 (해시태그 끝에 #협찬, 블로그 맨 끝에 안내, 협찬인데 내돈내산, 유튜브 설명란에만 안내, 영어 #ad·#gifted만, 할인받고 #체험단만, 잘 쓴 글).

### 4-2. 판정 기준
| 표시 | 항목 | 내용 | 감점 |
|---|---|---|---|
| 🔴 위반 | 표시 없음 | 대가를 받았는데 광고·협찬 표시가 없음. '광고'는 `[광고]`·`(광고)`·`#광고`·`광고입니다`·`유료 광고`·`광고 포함`·`광고:`처럼 표시 모양일 때만 인정 ("광고 모델처럼" 같은 다른 뜻은 인정 안 함) | −35 |
| 🔴 위반 | 반대 표현 | 대가를 받았는데 "내돈내산", "협찬 아님", "광고 아니에요", "직접 구매했어요", "제 돈으로 샀어요", "제공받지 않았어요"처럼 직접 샀다·광고가 아니라고 함 ("직접 구매하실 분은", "광고 없는 요금제" 같은 안내·상품 설명은 해당 없음) | −35 |
| 🔴 위반 | 표시 위치 | 인스타그램 첫 40자, 블로그 제목·첫 줄, 유튜브 제목에 표시가 없음 | −35 |
| 🟡 보완 | 애매한 표현 | thanks to, with, #ad, #sponsored, 체험단 등 | −15 |
| 🟡 보완 | 해시태그에 묻힘 | 표시가 해시태그뿐이고 해시태그가 5개 이상 | −15 |
| 💡 팁 | 대가 미기재 | 무엇을 받았는지 구체적으로 적지 않음 | −5 |

- 위반이 하나라도 있으면 **위반 위험**, 보완만 있으면 **보완 필요**, 그 외 **적합**
- 대가 없음(내돈내산)을 고르면 표시 의무가 없으므로 적합으로 나옵니다.

### 4-3. 고친 글 사용
1. 점검 결과 아래 **이렇게 고쳐서 올리세요** 카드에 수정본이 나옵니다.
   - 애매한 표현·반대 표현이 든 해시태그와 해시태그 표시(#광고·#협찬)는 해시태그째, 문장 속 반대 표현("협찬 아님" 등)·애매한 표현("Sponsored by", "thanks to", 체험단 등)은 그 문장을 통째로 지우고 (문장 속 "내돈내산"은 단어만 지움)
   - 첫 부분에 `[협찬] (업체)로부터 제품(서비스)을 무상으로 제공받아 작성한 글입니다.` 같은 문장을 넣습니다 (현금이면 `[광고] … 원고료를 받아`).
2. **고친 글 복사** → 인스타그램·블로그에 그대로 붙여넣기
3. **고친 글로 점검**을 누르면 수정본을 다시 점검해 적합인지 확인할 수 있습니다.
4. 재점검 결과 위의 **← 원래 글로 돌아가기 (OO점)**을 누르면 고치기 전 글과 원래 점검 결과로 돌아가 비교할 수 있습니다. (처음부터 직접 점검했을 때는 이 버튼이 보이지 않습니다.)

### 4-4. 이력·통계
- 점검할 때마다 이력에 자동 저장됩니다 (최근 100개).
- **이력** 탭에서 기록을 누르면 원래 글과 점검 결과를 다시 볼 수 있고, 삭제할 수 있습니다.
- 이력 상세 창은 휴대폰 **뒤로 가기**를 누르면 닫힙니다.
- **통계** 탭의 차트에서 가장 많이 틀린 항목이 진한 색으로 표시되고, 아래에 다음 글에서 지킬 한 가지를 알려 줍니다.

## 5. 자주 묻는 질문
- **데이터는 어디에 저장되나요?** 이 휴대폰의 브라우저에만 저장됩니다. 글이 서버로 전송되지 않습니다.
- **인터넷이 없어도 되나요?** 네. 한 번 연 뒤에는 앱 파일이 휴대폰에 저장되어 인터넷 없이도 점검·이력·통계·가이드를 모두 쓸 수 있습니다.
- **기록을 지우려면?** 이력 상세에서 하나씩 지우거나, 가이드 → **모든 기록 지우기** (되돌릴 수 없음).
- **정부에서 만든 앱인가요?** 아니요. 공정거래위원회 심사지침을 참고해 만든 개인 개발 앱이며 정부 기관과 관계없습니다. 결과는 참고용이고 법률 자문이 아닙니다.
- **이미지·영상 속 표시도 점검하나요?** 아니요. 글(텍스트)만 점검합니다. 유튜브는 영상 속 표시를 따로 안내합니다.
