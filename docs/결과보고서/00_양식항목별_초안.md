### 한 줄 소개
```
협찬을 처음 받는 크리에이터가 글을 올리기 전에 붙여넣으면 공정위 기준으로 뒷광고 위험을 찾아 고친 글까지 만들어 주고, 광고주는 올라온 게시물을 같은 기준으로 일괄 검수해 수정 요청과 크리에이터 섭외까지 할 수 있는 모바일 웹앱
```

### 해결한 문제
```
○ 협찬을 막 받기 시작한 대학생·소규모 크리에이터는 업체가 "자연스럽게 올려 주세요"라고만 해서 "#협찬"을 해시태그 맨 끝에 붙이면 된다고 생각하고, 몰라서 뒷광고를 하게 된다. 공정위가 2021~2025년 모니터링한 SNS 뒷광고 의심 게시물은 약 10만 9천 건(2025년만 2만 2,675건)이고, 상위 인플루언서 광고 글 582건 중 대가를 밝힌 글은 29.9%에 그친다(한국소비자원). 2024년 적발 유형은 부적절한 위치 39.4%, 미표시 26.5%, 부적절한 표현 17.3%로 '어디에·어떤 말로' 표시할지 모르는 문제가 83.2%다.
○ 체험단을 운영하는 광고주(동네 가게·브랜드 마케터)는 게시물 수십 개를 하나씩 열어 표시 위치를 눈으로 확인하고, 수정 요청 문구를 매번 새로 쓰며, 크리에이터 섭외 DM과 선착순 선발을 엑셀·메모로 따로 관리한다. 뒷광고가 적발되면 광고를 맡긴 사업자도 제재 대상이다.
○ 기존 방식의 한계: 심사지침은 길고 법률 용어라 읽히지 않고, 공정위 점검은 이미 올라간 글을 적발한 뒤 시정을 요청하는 사후 방식이다. 해외 점검 도구는 미국 FTC 기준이라 "#ad"를 정답으로 보고 고친 글을 만들어 주지 않는다.
```
📎 자료: `01_PRD.md` 1. 문제, `../01_기획서.md` 문제의 근거

### 주요 사용자 및 사용 장면
```
○ 주 사용자: ① 팔로워 1천~1만 명의 대학생·소규모 크리에이터(인스타그램·블로그·유튜브) ② 체험단·협찬 캠페인을 운영하는 광고주(소상공인, 브랜드·대행사 마케터)
○ 크리에이터: 협찬 후기를 올리기 직전, 휴대폰에서 글을 붙여넣고 30초 안에 점검 → 고친 글을 복사해 바로 업로드
○ 광고주: 캠페인 게시물이 올라온 뒤 매장 카운터·사무실에서 휴대폰으로 일괄 검수, 글을 복사할 수 없으면 인플루언서 휴대폰·회의실 모니터 화면을 카메라로 스캔. 다음 행사를 열 때 크리에이터 DB에서 골라 DM을 보내고 선착순으로 선발
○ 사용 기기: 휴대폰 브라우저(설치·로그인 없음), PC 브라우저에서도 동작
```
📎 자료: `01_PRD.md` 2. 대상 사용자

### 핵심 기능
```
① 광고 표시 점검·고친 글 (애드체크) : 올릴 글을 붙여넣으면 공정위 기준 6개 규칙으로 점수·판정·문제 항목을 보여 주고, 첫 줄에 [협찬] 문장을 넣은 고친 글을 복사·재점검할 수 있다
② 게시물 일괄 검수·수정 요청 (애드체크 비즈) : 캠페인 게시물을 붙여넣거나 화면을 찍어(한글 OCR) 한 번에 검수하고, 수정 요청 메시지 복사 → 수정본 재검수 → 확인 완료까지 조치 상태를 관리한다
③ 협업 크리에이터 DB·행사 DM·선착순 선발 (애드체크 비즈) : 크리에이터를 분야별로 관리하고, 행사 초대 DM을 사람별 문구로 보내고, 신청 시각(밀리초) 순으로 선발·대기를 자동 표시한다
```
📎 자료: `01_PRD.md` 4. 기능 요구사항, 캡처 `images/애드체크_03~05`, `images/애드체크비즈_04~05·11~18`

### 시연 시나리오
```
[애드체크] 접속 → '예시 글로 체험하기'(해시태그 끝에 #협찬) → 점검하기 → 30점 위반 위험(표시 위치·해시태그에 묻힘·애매한 표현) → 고친 글 복사 → 고친 글로 점검 → 100점 적합 → 통계에서 '자주 틀리는 항목: 표시 위치' 확인
[애드체크 비즈] 대시보드(준수율 38%) → 위반 게시물 → 수정 요청 메시지 복사 → 수정본 재검수 → 확인 완료·준수율 상승 → 화면 스캔(예시 화면 6장 → 추천 장면 → 한글 인식 → 등록 → 45점 위반 위험) → 협업 행사 DM 발송 → 선착순 선발·대기 자동 표시
```
📎 자료: `03_사용설명서_애드체크.md` 3절, `04_사용설명서_애드체크비즈.md` 3절, `../07_발표자료.md` 라이브 시연

### 반영한 전공 요소
```
○ 전공 지식: 인플루언서 마케팅에서 광고주–크리에이터 관계(협찬·원고료·체험단), 캠페인 운영 절차(모집 → 섭외 DM → 선발 → 게시 → 검수 → 수정 요청), 플랫폼별 노출 구조(인스타그램 '더보기' 앞 약 40자, 블로그·유튜브 제목)를 기능에 반영
○ 실제 기준·데이터: 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」(2024-09-01 개정 시행)을 6개 점검 규칙(표시 없음·반대 표현·표시 위치·애매한 표현·해시태그에 묻힘·대가 미기재)으로 정리. 공정위 2024 적발 유형 통계(위치 39.4%·미표시 26.5%·표현 17.3%)로 규칙 우선순위를 정함
○ 현장 용어·절차 반영: '협찬·광고·유료광고·제공받아', '내돈내산', '체험단', 'thanks to·#ad'(외국어 표현) 같은 현장 표현을 그대로 판별하고, 광고주 화면은 캠페인·준수율·수정 요청·조치 상태(미조치/수정 요청함/확인 완료), 협업 행사·DM 템플릿·선착순 선발처럼 실제 캠페인 운영 순서대로 구성
```

### 현장 적용 및 기대효과
```
○ 활용 방안: SNS마케팅 수업의 광고 표시 실습 도구(학생이 쓴 협찬 글을 점검·수정), 체험단·서포터즈 활동 학생의 게시 전 점검, 지역 소상공인 체험단 운영 시 검수·섭외 도구, 마케팅 대행사의 캠페인 검수
○ 기대효과: 게시물 1건 점검 30초(예시 글 30점 → 고친 글 100점), 광고주 검수는 붙여넣기 즉시 판정 + 수정 요청 메시지 자동 작성으로 게시물당 확인·문구 작성 시간 단축(샘플 캠페인 준수율 38% → 50%), 공정위 적발 유형 상위 3개(83.2%)를 게시 전에 예방. 화면 스캔은 흐림·줄무늬가 섞인 6장 중 추천 장면의 글자 일치율 100%
```

### 주요 프롬프트 및 개발 과정
```
○ 결과물 품질에 가장 큰 영향을 준 프롬프트
 1. "주제가 전공을 연계한 문제해결이야. 내 전공이 SNS마케팅 전공인데 어떤 주제가 적당한지 검토해 줘" → 후보 5개 중 '뒷광고 체크기' 선정, 대회 시작 18분 만에 핵심 기능 동작
 2. "애드체크를 사용하지 않는 인플루언서들의 글을 광고주가 점검해야 하는 경우도 있다면 이를 점검하는 광고주용 앱도 필요하다" → 같은 규칙 엔진을 공유하는 광고주용 앱으로 확장(올리기 전 + 올라온 뒤 양쪽 예방)
 3. "모니터 화면 혹은 스마트폰을 촬영할 때 프레임의 불일치로 이미지가 확인하기 어려운 상황을 개선하기 위해 다회 촬영 후 선명한 화면을 선택하여…" → 선명도·줄무늬 점수와 중앙값 합성으로 추천 장면 OCR 100%
○ 막혔던 문제와 AI로 해결한 과정
 - 화면 스캔 합성본이 흐려 OCR 36% → 합성 전 ±5픽셀 위치 맞추기를 추가해 81%, 줄무늬를 '합성본과의 차이'로 측정해 글줄이 줄무늬로 잡히던 문제 해결
 - 두 앱의 판정이 달라질 위험 → 규칙 원본 한 곳 + npm run sync-rules 복사 규칙을 CLAUDE.md에 명시
 - 카메라가 휴대폰에서 안 켜짐(https 필요) → 보안 연결일 때만 카메라 표시, 사진 불러오기·예시 화면으로 대체
 - 리허설 배포본 덮어쓰기 위험 → 배포 프로젝트 이름을 새 앱 이름으로 분리
○ 질문·검토형 프롬프트("유사한 앱이 있나?", "DB는 어떻게 처리하지?")가 많았고, 여기서 광고주용 앱과 3단계 데이터 로드맵이 나옴
※ 프롬프트 캡처는 결과물 제출 폼에 별도 업로드 (원문: docs/프롬프트기록.md, 분석 차트: docs/analysis/)
```

```
○ 화면 스캔 OCR은 흐린 사진·작은 글씨에서 정확도 저하 → 기울기·원근 보정, 글자 영역 자르기, 여러 장 결과 합치기
```
