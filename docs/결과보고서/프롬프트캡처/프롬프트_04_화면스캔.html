Changes to frames.ts (it was already written, but these were needed):

  • Stripe score: the old measure counted the text lines themselves as stripes, so every frame showed 줄무늬 많음. It now measures each frame against the median of all frames, so only stripes that move between shots count.
  • Composite alignment: frames are now shifted into line before they're merged. Without this, the composite read only 36% of the text; with it, 81%.
