광고주용 앱 애드체크 비즈를 sns-ma/advertiser 하위 폴더에 별도 앱으로 만들었고, 문서는 docs/advertiser/에 따로 저장했습니다. 기존 크리에이터용 앱의 코드는 건드리지 않았습니다. 지금 10:22입니다.

폴더 구성

sns-ma/
├─ src/               ← 애드체크 (크리에이터용, 남색)
├─ advertiser/        ← 애드체크 비즈 (광고주용, 청록색)
│  └─ src/pages/      ← 대시보드, 게시물, 캠페인
└─ docs/
   ├─ 01~06 ...       ← 크리에이터용 문서
   └─ advertiser/     ← 광고주용 기획서, 기술설계, 사용설명서

애드체크 비즈 기능

탭하는 일
대시보드캠페인 선택, 게시물 수·준수율·조치 필요 수, 판정별 게시물 수 차트, 조치가 필요한 게시물 목록
게시물인플루언서 계정과 글을 붙여넣으면 바로 검수. 누르면 문제 항목과 수정 요청 메시지가 나옴
캠페인캠페인(브랜드, 제공한 대가)을 한 번만 등록하면 게시물마다 다시 입력할 필요 없음

수정 요청 흐름

  1. 메시지를 복사하면 상태가 자동으로 "수정 요청함"으로 바뀝니다.
  2. 인플루언서가 고친 글을 붙여넣어 다시 검수합니다.
  3. 적합이면 상태가 자동으로 "확인 완료"로 바뀝니다.
