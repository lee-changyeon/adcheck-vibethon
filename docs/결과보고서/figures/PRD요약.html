🎯 목표

  • 크리에이터: 30초 점검 → 고친 글 복사로 몰라서 하는 뒷광고 0건
  • 광고주: 캠페인 게시물 일괄 검수 + 수정 요청, 크리에이터 섭외까지 한곳에서
  • 공정위 적발 유형 상위 3개(위치·미표시·표현 83.2%)를 잡는 규칙을 두 앱이 공유

👤 사용자

  • 대학생·소규모 크리에이터 — 협찬을 막 받기 시작, 표시 규칙을 모름 (휴대폰)
  • 체험단 운영 광고주 — 동네 가게 사장님·브랜드 마케터, 게시물 수십 개 검수 (휴대폰)
