### 1. 표지
- 화면: 애드체크 & 애드체크 비즈 / "올리기 전엔 크리에이터가, 올린 뒤엔 광고주가. 뒷광고를 양쪽에서 막는 광고 표시 점검 앱" / SNS마케팅 전공 · 개인 참가
- 메모: 안녕하세요, SNS마케팅 전공 [이름]입니다. 제가 만든 건 뒷광고를 막는 앱 두 개입니다. 인플루언서가 글을 올리기 전에 쓰는 애드체크, 그리고 광고주가 올라온 글을 검수하는 애드체크 비즈입니다.

### 2. 문제 — 뒷광고: 대가를 받고도 광고임을 숨긴 글
- 화면: 약 10만 9천 건(2021~2025 공정위 모니터링 의심 게시물), 29.9%(상위 인플루언서 광고글 582건 중 대가를 밝힌 비율), 2024년 적발 유형 부적절한 위치 39.4% · 표시 안 함 26.5% · 부적절한 표현 17.3%
- 출처: 서울경제TV·SBS 뉴스, 공정위 국민생각함·서울경제, 한국소비자원 조사(어패럴뉴스 보도) — `01_기획서.md` "문제의 근거"
- 메모: 공정위가 5년간 찾아낸 의심 게시물만 약 10만 9천 건이고, 상위 인플루언서 광고글도 대가를 제대로 밝힌 건 29.9%뿐입니다. 적발 유형 1위는 '표시를 안 한 것'이 아니라 '잘못된 위치에 한 것'입니다.

### 3. 원인 — 숨기려는 게 아니라, 규칙을 몰라서 생깁니다
- 화면: 업체 "자연스럽게 올려 주세요" / 크리에이터 "#협찬, 해시태그 맨 끝에 달면 되겠지" / 어떤 말로?(한글 '광고'·'협찬', thanks to·#ad·Sponsored는 부적절) / 어디에?(첫 부분, 본문 중간·댓글·더보기·해시태그 더미는 인정 안 됨)
- 기준: 2024-09-01 시행 개정 심사지침 (어패럴뉴스·김앤장)
- 메모: 심사지침은 길고 법률 용어라 잘 읽지 않습니다. 핵심은 어떤 말로, 어디에. 게다가 공정위 점검은 이미 올라간 글을 적발하는 사후 방식입니다.

### 4. 해결 — 같은 점검 규칙, 두 개의 앱, 두 번의 확인
- 화면: 애드체크(올리기 전에 점검) → 애드체크 비즈(올라온 뒤에 검수), 하단 "서버 없이 휴대폰 안에서만 동작합니다"
- 메모: 두 앱은 같은 점검 규칙 6개를 씁니다. 모든 계산이 휴대폰 브라우저 안에서 이뤄져 아직 공개하지 않은 협찬 글이 서버로 가지 않습니다. 로그인·개인정보 수집이 없고 결과가 즉시 나옵니다 — **개인정보 보호가 강점**.

### 5. 애드체크 (크리에이터용)
- 화면: 예시 글 "해시태그 끝에 #협찬"(베이글하우스) **30점 위반 위험** (표시 위치 −35, 해시태그에 묻힘 −15, 애매한 표현 −15, 대가 미기재 −5) → 첫 줄 `[협찬] 베이글하우스로부터 제품을 무상으로 제공받아 작성한 글입니다.`를 넣은 고친 글 **100점 적합**
- 메모: 점수만 주고 끝나지 않고 바로 올릴 수 있는 고친 글을 만들어 줍니다. 이력·통계 탭은 내가 자주 틀리는 항목을 보여 줘 습관을 고치게 합니다.

### 6. 점검 규칙 6개 — 공정위 적발 유형 상위 3개(83.2%)를 겨냥
| 판정 | 항목 | 잡아내는 것 | 감점 | 적발 유형 |
|---|---|---|---|---|
| 위반 | 표시 없음 | 대가를 받았는데 광고·협찬 표시 없음 | −35 | 표시 안 함 |
| 위반 | 반대 표현 | "내돈내산", "협찬 아님" | −35 | 표시 안 함 |
| 위반 | 표시 위치 | 인스타 첫 40자, 블로그 제목·첫 줄, 유튜브 제목에 없음 | −35 | 부적절한 위치 |
| 보완 | 애매한 표현 | thanks to, with, #ad, #sponsored, 체험단 | −15 | 부적절한 표현 |
| 보완 | 해시태그에 묻힘 | 표시가 해시태그뿐 + 해시태그 5개 이상 | −15 | 부적절한 위치 |
| 팁 | 대가 미기재 | 무엇을 받았는지 안 적음 | −5 | 표시의 명확성 |
- 하단 안내: 결과는 심사지침을 바탕으로 한 **참고용 점검이며 법률 자문이 아님**
- 메모: AI 없이 규칙으로만 판정해 결과가 늘 같고 즉시 나옵니다.

### 7. 애드체크 비즈 (광고주용)
- 화면: 01 캠페인 만들기 → 02 게시물 일괄 검수 → 03 수정 요청 메시지(복사하면 '수정 요청함') → 04 수정본 재검수(적합이면 '확인 완료'), 대시보드 준수율 **38% → 50%**(시연 샘플), 메시지 예시
- 메모: 애드체크를 쓰지 않는 인플루언서의 글은 광고주가 검수해야 합니다. 문제 항목과 수정 예시가 들어간 메시지를 자동으로 만들어 줍니다.

### 8. 화면 스캔
- 화면: 문제(깜빡임 줄무늬·모아레·손떨림) → 01 연속 8장(130ms) → 02 선명도(라플라시안 분산) ÷ 줄무늬 점수 → 03 위치 맞춘 뒤 픽셀별 중앙값 합성 → 04 한글 OCR(tesseract.js, 휴대폰 안) → 검수
- 측정(예시 6장 + 합성본, OCR 글자 일치율): 추천 장면 100%, 합성본 36% → 81%(위치 맞추기 전 → 후), 많이 흐린 장 0~1% — `advertiser/docs/02_기술설계.md`
- 메모: 한 장만 찍으면 0%가 될 수도 있어서 여러 장 찍고 고르는 게 필요합니다. 사진도 휴대폰 밖으로 나가지 않습니다.

- 타임라인: 09:37 주제 공개 → 09:44 주제 선정(후보 5개 중) → 09:55 규칙 엔진 + 크리에이터 앱 → 10:11 근거 통계·유사 서비스 조사 → 10:21 광고주 앱 → 10:40 화면 스캔 → 10:54 두 앱 배포 (`03_작업목록.md`, `advertiser/docs/03_작업목록.md`)
- AI 협업: Claude Code, 프롬프트 24개·평균 454자 (`docs/analysis/요약.md`, 09:37~10:53 기준), 미리 준비한 규칙(CLAUDE.md)·문서 템플릿, 기능마다 타입·린트·빌드 자동 검사, 프롬프트 자동 기록
- 세션 분할: 크리에이터 앱 / 광고주 앱·화면 스캔 / 배포 / 보고서·향후계획 / 발표자료를 각각 세션으로 나눠 병렬 진행

### 12. 향후 계획 — 필요한 만큼만, 동의를 받고, 글 원문은 저장하지 않고
- 데이터 로드맵: 지금(브라우저에만 저장) → 1단계 JSON 백업(서버 없음) → 2단계 익명 통계(문제 항목·점수만, 글·계정 제외, 끄기 가능) → 3단계 로그인 + 클라우드(수집 동의, 90일 보관, 탈퇴 시 즉시 삭제). 로그인 없는 방식은 계속 유지
